# Personal Portfolio Website

A clean, responsive personal portfolio website built with HTML5, CSS3, and JavaScript. Designed to showcase my projects, skills, and contact information.

---

## Live Demo
Access the live portfolio:
https://daminokun.github.io/portfolio/

---

## Features
- Smooth Navigation: Simple access to About, Projects, and Contact sections.
- Showcase Grid: Display cards for featured projects with live demo and GitHub repository links.
- Responsive Layout: Optimized for viewing on desktops, tablets, and mobile devices.

---

## Tech Stack
- HTML5: Semantic structure.
- CSS3: Modern layout using Flexbox and CSS Grid.
- JavaScript (ES6+): Client-side interaction.
